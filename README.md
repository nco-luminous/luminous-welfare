## 運用ルール

- **このリポジトリが唯一の正本**（ローカルコピーで二重管理しない）
- 編集は `index.html` を直接修正 → commit → push（数分でPagesに反映）
- 写真を追加するときの注意:
  - Web用にリサイズ（横1600px程度）
  - **EXIF回転タグを除去**（残っているとブラウザで横向きになる）
  - 利用者・第三者が写る場合は掲載同意とぼかし処理を確認
